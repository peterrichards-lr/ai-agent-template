# About these docs

This site is the documentation for this project, built with MkDocs Material from the
Markdown files in the repository. The repository is the source: every page here is a file
there, and a change to the docs is a pull request like any other.

Each page shows when it was last updated and when it was last reviewed. A page whose review
date is old may describe behaviour that has since changed; check it against the code before
relying on it.

Found something wrong or out of date? Open an issue in the repository.
